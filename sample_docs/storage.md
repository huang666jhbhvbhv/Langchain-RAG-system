# AtlasDocs 存储与增量同步

本地索引存储在 SQLite，文档片段和向量在同一数据库事务中更新。
根据源文件内容的 SHA-256 判断是否变化，不仅依赖修改时间。
未变化文件不重复向量化；新增和修改文件重算片段；删除源文件后同步会清除对应旧片段。

解析失败或 Embedding 接口异常时，中止本次更新并保留此前可用的索引。
同一知识库的写入通过文件锁串行化，读取使用已提交的一致快照。
一个知识库绑定一个文档根目录，换项目时应创建新知识库。

完整重建成功前不删除旧索引。更换 Embedding 模型时必须重建，不可混用不同向量空间。
文档及向量默认保存明文，不提供数据库加密和多租户权限管理。
