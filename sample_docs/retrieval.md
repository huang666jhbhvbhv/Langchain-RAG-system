# AtlasDocs 检索与引用

hybrid 是混合检索，结合向量相似度和 BM25 关键词匹配，并用 RRF 融合排名。
向量检索帮助匹配语义相近问题；BM25 帮助匹配精确配置名、错误码和英文标识符。
RRF 使用 1/(60+rank) 累加两路排名贡献，它不是概率，也不是答案置信度。

Markdown 和 TXT 的片段记录源文件与起止行号。PDF 记录页码，提取文本顺序可能不同于视觉排版。
生成回答时引用 [1]、[2] 等证据编号。无足够依据时，应说明文档没有相关信息。
程序会验证引用编号范围和正文一致性，但不能保证引用在语义上支持全部回答。

向量采用余弦相似度，检索阈值需要结合具体 Embedding 模型和问题集调参。
不能因为找到了 Top-K 片段就认为一定有答案。
